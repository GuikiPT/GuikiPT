GUIKIPT BOTS PRIVACY POLICY

Effective Date: October 17, 2025
Last Updated: June 11, 2026

1. OVERVIEW

This Privacy Policy explains how GuikiPT Bots (“the Bot”, “we”, “us”, or “our”) collect, process, store, and protect data when used on Discord servers, in direct messages, through slash commands, through dashboard features, or through connected integrations.

This policy applies to all Discord bots, dashboards, APIs, and related services operated under GuikiPT Bots, unless a specific bot or service provides its own separate privacy policy.

By adding, configuring, or using a GuikiPT Bot, you acknowledge that the Bot may process data as described in this policy.

2. DATA CONTROLLER

For the bot operations described in this policy, GuikiPT is the data controller where it determines the purposes and means of processing.

Server administrators may also act as independent controllers for how they configure the Bot inside their own Discord servers, especially for moderation logs, automod rules, audit features, tags, custom commands, or other server-specific features.

3. DATA WE MAY PROCESS

The exact data processed depends on which bot features are enabled in a server.

3.1 Discord Identifiers

We may process Discord-related identifiers, including:

* User IDs
* Server/guild IDs
* Channel IDs
* Role IDs
* Message IDs
* Interaction IDs
* Thread IDs
* Webhook IDs
* Command IDs
* Application IDs

These identifiers are used to make bot features work correctly, such as permissions, moderation actions, command handling, server configuration, logging, and automation.

3.2 Basic Discord Profile Data

Where needed, the Bot may process limited Discord profile information, including:

* Username
* Display name
* Avatar URL
* Bot account status
* Server nickname
* Public Discord account flags
* Roles inside a server
* Server membership status

This data is used only where required for bot functionality, permissions, moderation, dashboards, logs, or user-facing commands.

3.3 Server Configuration Data

We may store configuration data set by server administrators, including:

* Bot prefixes
* Enabled or disabled features
* Moderation settings
* Automod rules
* Allowed or ignored channels
* Allowed or ignored roles
* Logging channels
* Staff roles
* Tag settings
* Custom commands
* Welcome or leave settings
* Starboard/skullboard settings
* Dashboard preferences
* Integration settings

This data is required for the Bot to remember how each server wants the Bot to behave.

3.4 Usage and Technical Metadata

We may process technical and usage metadata, including:

* Command usage
* Timestamps
* Error logs
* Rate limit events
* Feature usage
* Bot uptime and reliability logs
* Security and abuse-prevention logs
* API request metadata
* Guild install/removal events

This data is used to operate the Bot, debug issues, prevent abuse, detect spam, enforce limits, and improve reliability.

3.5 Message Content

The Bot may access message content only when a feature requires it and Discord allows it.

Message content may include:

* Message text
* Message embeds
* Message attachments or attachment metadata
* Message components
* Poll data
* Deleted or edited message content, if a server logging feature is enabled
* Messages sent in direct messages to the Bot
* Messages mentioning the Bot
* Messages used with context menu commands
* Messages processed by moderation, automod, tag, trigger, logging, or support features

Message content is only used for the feature that needs it. Where possible, GuikiPT Bots prefer slash commands, buttons, select menus, context menu commands, and other interaction-based features instead of reading general message content.

If message content is stored, it is stored only as long as needed for the enabled feature, moderation evidence, logging, abuse prevention, debugging, or legal/platform compliance.

3.6 Moderation and Safety Data

If moderation features are enabled, the Bot may process and store moderation and safety data, including:

* Warnings
* Mutes/timeouts
* Kicks
* Bans
* Notes
* Case IDs
* Moderator IDs
* Target user IDs
* Reasons
* Evidence
* Deleted or edited message logs
* Automod triggers
* Appeal or report data
* Anti-spam or anti-raid detection data

This data is used to help server staff keep their communities safe and enforce server rules.

Server administrators are responsible for making sure their members understand when moderation logging or automod features are enabled.

3.7 Dashboard and Authentication Data

If a web dashboard is used, we may process dashboard and authentication data, including:

* Discord OAuth2 account ID
* Discord username and avatar
* Servers you can manage
* Permissions in those servers
* Dashboard session data
* CSRF/security tokens
* Login timestamps
* Selected server settings

If Discord provides your email address through an authorized OAuth2 scope, it may be processed only for account access, support, security, or account identification. We do not sell this information.

3.8 Integration Data

Some features may connect with third-party services, such as websites, APIs, game servers, status pages, payment providers, or server dashboards.

Depending on the enabled integration, we may process integration data, including:

* External service IDs
* Integration configuration
* API response data needed for the feature
* Webhook payloads
* Subscription or entitlement references
* Linked account identifiers

We only process integration data as needed to provide the configured feature.

3.9 Payment and Premium Data

If paid features are offered, payments may be handled by Discord or a third-party payment provider.

We do not intentionally store full payment card numbers, bank details, or payment credentials.

We may store limited payment-related references, including:

* Discord entitlement IDs
* Subscription status
* Product or plan name
* Purchase timestamps
* Renewal or cancellation status
* Payment provider customer/reference IDs

This is used to activate, manage, or verify premium features.

4. DATA WE DO NOT INTENTIONALLY COLLECT

GuikiPT Bots do not intentionally collect:

* Discord passwords
* Discord login tokens
* Full payment card details
* Government IDs
* Sensitive health information
* Financial account information
* Biometric data
* Private information unrelated to bot functionality

You should not send passwords, tokens, personal documents, private keys, or other sensitive information to the Bot.

5. WHY WE PROCESS DATA

We process data for the following purposes:

* To provide bot commands and core features
* To save server configuration
* To enforce server moderation settings
* To provide automod, anti-spam, anti-raid, and security features
* To operate tags, custom commands, logging, reminders, tickets, or automation features
* To provide dashboards and admin controls
* To handle premium access or subscriptions, where applicable
* To debug errors and improve reliability
* To prevent abuse, spam, raids, and misuse
* To comply with Discord policies, platform requirements, and API limits
* To respond to lawful requests or legal obligations
* To enforce this policy, bot terms, and platform rules

6. LEGAL BASES UNDER GDPR / UK GDPR

Where GDPR or UK GDPR applies, we rely on one or more of the following legal bases.

6.1 Performance of a Contract

Processing is necessary to provide the Bot features requested by users or server administrators.

6.2 Legitimate Interests

Processing is necessary for legitimate interests such as security, moderation, abuse prevention, debugging, reliability, and service improvement, while respecting user privacy.

6.3 Consent

Some optional features may require consent or server-level opt-in, especially features involving message content, integrations, premium services, or dashboard access.

6.4 Legal Obligation

Processing may be required to comply with applicable laws, lawful requests, or platform enforcement obligations.

7. MESSAGE CONTENT AND PRIVILEGED INTENTS

Some Discord data is only available through privileged intents or specific Discord permission flows.

GuikiPT Bots only enable privileged intents where needed for bot functionality and where allowed by Discord.

These may include:

* Message Content Intent
* Guild Members Intent
* Guild Presences Intent

Message Content Intent may be used for features including:

* Prefix commands
* Moderation and automod
* Spam or scam detection
* Message logging
* Custom triggers
* Tags or custom responses
* Support or ticket features
* Context-aware commands

Where possible, the Bot uses Discord interaction features instead, including:

* Slash commands
* Buttons
* Select menus
* Autocomplete
* Modals
* Context menu commands

Message content is not used to train AI or machine learning models unless expressly allowed by Discord and clearly disclosed in a separate policy or feature notice.

8. DATA SHARING

We do not sell personal data.

We do not disclose Discord API data to data brokers, advertising networks, or unrelated monetization services.

We may share data only in limited cases.

8.1 Discord

Data is processed through Discord’s platform, APIs, gateway events, interactions, and developer tools as necessary for the Bot to function.

8.2 Service Providers

We may use trusted service providers for hosting, databases, logging, monitoring, backups, analytics, security, payments, or infrastructure.

Service providers may only process data as instructed and only for providing services to GuikiPT Bots.

8.3 Server Administrators

Some data, such as moderation logs, automod results, reports, warnings, or command logs, may be visible to server administrators or staff depending on how the server configures the Bot.

8.4 Legal or Safety Reasons

Data may be disclosed where required by law, legal process, platform enforcement, safety investigations, or to protect users, communities, GuikiPT Bots, Discord, or others.

8.5 User-Directed Sharing

If a user or server administrator enables an integration or directs the Bot to send data to another service, the Bot may share the minimum data needed for that configured feature.

9. DATA RETENTION

We keep data only as long as needed for the purpose it was collected, unless a longer period is required by law, platform rules, security needs, or legitimate moderation purposes.

General retention guidelines include:

* Server configuration:
  Retained while the Bot remains in the server or the feature remains enabled.

* Command usage metadata:
  Retained for a limited period needed for debugging, analytics, and abuse prevention.

* Technical logs:
  Usually retained short-term, unless needed for security or incident investigation.

* Moderation logs:
  Retained until deleted by server staff, the server removes the Bot, or the data is no longer needed.

* Message content:
  Not stored longer than needed for the enabled feature.

* Dashboard sessions:
  Retained until logout, expiry, or security cleanup.

* Premium references:
  Retained while needed to manage premium access, accounting, disputes, or legal obligations.

* Backups:
  Deleted or overwritten on a regular backup rotation.

When the Bot is removed from a server, server configuration may be deleted immediately or after a reasonable grace period to allow recovery from accidental removal.

Some moderation or safety records may be retained longer where needed to prevent abuse, investigate misuse, respond to legal requests, or comply with Discord platform rules.

10. DATA DELETION

Users and server administrators may request deletion of data associated with them or their server.

A deletion request may include:

* User-specific data
* Server configuration data
* Moderation case data, where legally and technically possible
* Dashboard account/session data
* Premium-related references, where no longer legally required

Some data may not be deleted immediately if retention is required for:

* Legal obligations
* Fraud or abuse prevention
* Security investigations
* Payment disputes
* Discord enforcement
* Protecting the rights or safety of users or communities

Deleting bot data does not delete messages, logs, or data stored directly by Discord or by other bots/services.

Server administrators who add or configure GuikiPT Bots are responsible for:

* Ensuring the Bot is used lawfully in their server
* Informing members when logging, moderation, automod, or message-processing features are enabled
* Configuring permissions appropriately
* Avoiding unnecessary collection of personal data

* Removing or disabling features they no longer need

Unless clearly disclosed otherwise:

* Message content is not used to train AI models
* AI features should be opt-in or clearly configured

* AI output may be inaccurate and should not be treated as professional advice

Specific AI features may have additional notices depending on how they work and which providers are used.
